## Odin bindings for frametimer.h
Currently, it's Windows only.

### Build
```
$ pwd
C:\Work\odin\odin-frametimer

$ cd src
$ build.bat
```

### Run an example
```
$ pwd
C:\Work\odin\odin-frametimer

$ odin run examples\basic.odin -file
```
